When were you diagnosed? Cannot be in the future.
The native date input, deliberately: accessible, localised by the platform, and free. The browser's own locale decides the display order, so the field is never labelled dd/mm. The browser checks against the device's local date; the server re-checks in UTC with a day of tolerance, so nobody far enough east or west is refused a correct answer.
