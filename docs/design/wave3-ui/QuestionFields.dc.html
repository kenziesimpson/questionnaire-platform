Question editor — the fields each type shows

Choosing the response type decides the rest of the dialog. Every field below is optional unless marked, and the editor's job is to make the six cross-field rules unrepresentable rather than report them: a save that trips one comes back 400 request/invalid, which the author should never see.

The response type is chosen once, on creation, and locked afterwards — a branching rule is typed to the question it reads, so changing a published question's type would invalidate rules in questionnaires the author cannot see from here. A Yes / No button beside the type row creates a single choice pre-filled with yes / no and editable labels.
